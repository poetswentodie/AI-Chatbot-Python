# AI Chatbot using Python

A simple rule-based AI chatbot developed using Python that can respond to basic user queries.

## Features
- Interactive command-line chatbot
- Responds to greetings and AI-related questions
- Simple conversational logic

## Technologies Used
- Python

## How to Run

1. Install Python
2. Download the project
3. Run the command:

python chatbot.py

## Example

You: hello  
Bot: Hello! How can I help you?

You: what is ai  
Bot: AI stands for Artificial Intelligence.
